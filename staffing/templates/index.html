File Format Specifications & Data Validation Rules

Employee File Schema & Validation Rules

Field / Column Data Type Status Rules & Specific Constraints
name String Required Full candidate/employee name. Cannot be empty.
email String Required Valid email format (e.g. user@domain.com). Must be unique. Existing emails update existing developer details.
title String Optional Job title (e.g. Staff AI Architect). Default: Senior Software Engineer.
hourly_cost Decimal Optional Hourly billable/cost rate in USD (>= 0). Default: 75.00.
max_weekly_hours Integer Optional Max available weekly hours capacity. Constraint: 1 to 80 (Default: 40).
skills Array / String Optional JSON: Array of objects [{"name": "Python", "proficiency_level": 5}]
CSV: Pipe-separated string Python:5|Django:4|PostgreSQL:3
Note: Proficiency scale is 1 (Novice) to 5 (Expert). Missing skills are created automatically in DB.
Sample Employee JSON Structure:
[
  {
    "name": "Jane Doe",
    "email": "jane.doe@benchzero.io",
    "title": "Lead Software Architect",
    "hourly_cost": 140.00,
    "max_weekly_hours": 40,
    "skills": [
      { "name": "Python", "proficiency_level": 5 },
      { "name": "PyTorch", "proficiency_level": 4 }
    ]
  }
]
Sample Employee CSV Format:
name,email,title,hourly_cost,max_weekly_hours,skills
Jane Doe,jane.doe@benchzero.io,Lead Architect,140,40,Python:5|PyTorch:4
Bob Smith,bob.smith@benchzero.io,Fullstack Dev,110,40,React:4|TypeScript:4|Node.js:3

Project & Role Slot Schema & Validation Rules

Field / Column Data Type Status Rules & Specific Constraints
name / project_name String Required Title of the project (e.g. Apex AI Platform).
client String Required Client or department name. Cannot be empty.
priority Integer Optional Project strategic priority. Constraint: 1 (Low) to 5 (Critical). Default: 3.
budget Decimal Optional Total budget in USD (>= 0). Default: 50000.00.
role_title String Required Title of the demand slot (e.g. Senior Backend Engineer).
start_date & end_date Date String Required Format: YYYY-MM-DD. Constraint: end_date must be >= start_date.
headcount_needed Integer Optional Number of developers needed (>= 1). Default: 1.
required_skills Array / String Optional JSON: Array [{"name": "Go", "min_proficiency": 4, "is_mandatory": true}]
CSV: Pipe-separated Go:4:mandatory|PostgreSQL:3:optional
Note: min_proficiency scale is 1 to 5. is_mandatory controls hard vs soft CP-SAT solver constraints.
Sample Project & Slot JSON Structure:
[
  {
    "name": "Titan Cloud Infrastructure",
    "client": "Titan Tech",
    "priority": 5,
    "budget": 200000.00,
    "description": "Multi-region AWS cloud migration",
    "slots": [
      {
        "role_title": "Lead Cloud Architect",
        "start_date": "2026-08-01",
        "end_date": "2026-11-01",
        "priority": 5,
        "headcount_needed": 2,
        "weekly_hours_required": 40,
        "required_skills": [
          { "name": "AWS", "min_proficiency": 4, "is_mandatory": true },
          { "name": "Kubernetes", "min_proficiency": 3, "is_mandatory": false }
        ]
      }
    ]
  }
]
Sample Project CSV Format:
project_name,client,priority,budget,description,role_title,start_date,end_date,slot_priority,headcount_needed,weekly_hours_required,required_skills
Titan Cloud,Titan Tech,5,200000,Cloud migration,Lead Cloud Architect,2026-08-01,2026-11-01,5,2,40,AWS:4:mandatory|Kubernetes:3:optional
